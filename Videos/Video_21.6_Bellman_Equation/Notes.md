# Reinforcement Learning Workflow

```text
Current State
      ↓
Choose Action
      ↓
Receive Reward
      ↓
Update Q-Matrix
      ↓
Move to Next State
      ↓
Repeat
```

Over time the Q-Matrix stores increasingly accurate action values.

---

# Creating the Q-Matrix

The Q-Matrix is initialized with zeros.

```python
import numpy as np

Q = np.zeros((6, 6))
```

Example:

```text
      A  B  C  D  E  F

A     0  0  0  0  0  0
B     0  0  0  0  0  0
C     0  0  0  0  0  0
D     0  0  0  0  0  0
E     0  0  0  0  0  0
F     0  0  0  0  0  0
```

Initially, the agent has no knowledge of the environment.

---

# Training Process

The Q-Matrix is populated through repeated learning episodes.

During each episode:

1. Select a state.
2. Choose an action.
3. Observe the reward.
4. Update the Q-value.
5. Move to the next state.
6. Repeat until the goal state is reached.

---

# Random Exploration

At the beginning of training, actions are selected randomly.

```text
Unknown Environment
        ↓
Random Actions
        ↓
Collect Rewards
        ↓
Update Q-Matrix
```

Random exploration helps the agent discover all possible paths.

---

# Bellman Equation Review

The Bellman Equation updates Q-values.

Conceptually:

```text
New Q-Value
      =
Current Reward
      +
Future Reward Potential
```

The update incorporates:

- Immediate reward
- Best future reward
- Learning rate
- Discount factor

---

# Q-Value Updates

Every action modifies the Q-Matrix.

Example:

Before:

```text
State A → B = 0
```

Reward discovered:

```text
+100
```

After update:

```text
State A → B = 80
```

The value increases because the path leads toward a desirable outcome.

---

# Multiple Episodes

One training episode is insufficient.

The algorithm repeatedly performs:

```text
Explore
      ↓
Learn
      ↓
Update Q-Matrix
      ↓
Repeat
```

Thousands of episodes may be required before convergence.

---

# Convergence

Convergence occurs when Q-values stabilize.

```text
Additional Episodes
        ↓
Little or No Change
        ↓
Optimal Policy Learned
```

At this point, the agent has effectively learned the environment.

---

# Finding the Optimal Path

Once training is complete, the Q-Matrix contains learned action values.

Example:

```text
Current State = B

Move Left  = 20

Move Right = 100
```

The agent chooses:

```text
Move Right
```

because it has the highest Q-value.

---

# Policy Extraction

A policy is generated by selecting the highest-valued action from each state.

```text
State
   ↓
Highest Q-Value
   ↓
Best Action
```

This policy represents the learned solution.

---

# Example Navigation Problem

Suppose the goal is to move from:

```text
State A
```

to:

```text
State F
```

After training:

```text
A → C → E → F
```

may emerge as the optimal route.

The agent discovers this path through experience rather than explicit programming.
