# Key Takeaways

✅ K-Means is an unsupervised clustering algorithm.

✅ The Elbow Method helps select the optimal number of clusters.

✅ Reinforcement learning learns through rewards and penalties.

✅ Q-Learning uses the Bellman Equation to update Q-values.

✅ The Q-Matrix stores learned state-action values.

✅ Deep Neural Networks contain input, hidden, and output layers.

✅ TensorFlow is a leading framework for deep learning.

✅ Image recognition is a common application of neural networks.
